# 因子注入与选择方案

日期：2026-06-09

## 当前结论

当前不是只支持 3 个因子。上次实测只注入 `UnitSpeed`、`Barrier`、`Avenger` 是为了先隔离验证加载链。

实际有两条入口：

- 脚本/银行注入入口：支持 69 个 mutator id，可一次注入多个。
- 大厅 `Attribute011` 入口：支持 58 个 `CustomAllowed` 因子，但当前是单选。

因此后续如果要做“选择多个因子后进图”，应以 `CampaignXCore.SC2Bank` 的 `Mutators` section 作为主入口；大厅属性只能作为单因子兼容入口，除非后续额外做多选 UI 或多槽位 Attribute。

## 运行时依赖

因子运行库来自：

- `Mods/kit_mutations.SC2Mod`
- 运行库：`Base.SC2Data/LibA070801C.galaxy`
- 数据表：`Base.SC2Data/GameData/Mutators.xml`

7vs1 地图通过 `LibE0EAE146_MutatorRuntime.galaxy` 桥接：

- `BankLoad("CampaignXCore", 1)` 读取银行。
- 清空当前 mutator 状态。
- 调用 `libA070801C_gf_EnableMutatorCustomMode()`。
- 对每个选中的 id 调用 `libA070801C_gf_EnableDisableMutator(true, mutatorId)`。
- 最后调用 `libA070801C_gf_StartAllEnabledMutators(enemyPlayer)`。

对应文件：

- 公共源：`Shared/7vs1PublicLibs/Base.SC2Data/LibE0EAE146_MutatorRuntime.galaxy`
- 每张地图本地副本：`Maps/*_7vs1.SC2Map/Base.SC2Data/LibE0EAE146_MutatorRuntime.galaxy`
- 测试启动脚本：`scripts/launch-7vs1-coop-test.ps1`

## 银行注入格式

银行文件：

- `Documents/StarCraft II/Banks/CampaignXCore.SC2Bank`
- `Documents/StarCraft II/Accounts/.../Banks/CampaignXCore.SC2Bank`

注入 section：

```xml
<Section name="Mutators">
  <Key name="Enabled">
    <Value int="1"/>
  </Key>
  <Key name="Preset">
    <Value int="0"/>
  </Key>
  <Key name="Selected.UnitSpeed">
    <Value int="1"/>
  </Key>
  <Key name="Selected.Barrier">
    <Value int="1"/>
  </Key>
  <Key name="Selected.Avenger">
    <Value int="1"/>
  </Key>
</Section>
```

规则：

- `Enabled=1` 表示启用银行注入。
- `Preset=0` 表示不用内置预设，只看 `Selected.*`。
- `Selected.<MutatorId>=1` 表示启用该因子。
- 没有 `Mutators` section 或 `Enabled=0` 时，银行入口关闭，运行时回退到大厅 `Attribute011` 单选或默认关闭。

## 启动脚本用法

测试脚本会自动写两处银行，并安装 live map、依赖 mod，然后启动地图。

示例：

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File "合作指挥官-起义狂潮\scripts\launch-7vs1-coop-test.ps1" `
  -MapSource "E:\Code\MyMod\SC2\合作指挥官-起义狂潮\Maps\ttosh02_7vs1.SC2Map" `
  -LiveMapName "ttosh02_7vs1.SC2Map" `
  -Commanders @("TerranRaynor") `
  -Mutators "UnitSpeed,Barrier,Avenger"
```

`-Mutators` 支持逗号或分号分隔，也支持数组：

```powershell
-Mutators "UnitSpeed,Barrier,Avenger"
-Mutators @("UnitSpeed", "Barrier", "Avenger")
```

不传 `-Mutators` 且 `-MutatorPreset 0` 时，脚本会移除旧的银行 `Mutators` section，避免上次测试残留。

## 后续如何结合选择因子

推荐分两阶段做。

阶段 1：继续使用银行作为多选入口。

- 外部选择器或测试脚本收集 mutator id 列表。
- 写入 `CampaignXCore.SC2Bank/Mutators`。
- 地图启动后由 `LibE0EAE146_MutatorRuntime` 读取并启用。
- 优点是不用改大厅 UI，已经实际进图验证过加载链。

阶段 2：做正式选择界面。

可选方案：

1. 外部启动器选择
   - 做一个本地 UI 或脚本参数面板，选择最多 10 个因子后写银行。
   - 最稳，和当前脚本路径一致。

2. 多槽位 Attribute
   - 增加 `Attribute011..Attribute020`，每个槽位单选一个因子。
   - 地图启动时读取多个 Attribute 并去重。
   - 优点是仍走大厅；缺点是 Attribute 数量多，界面会很长，且仍不是真正的复选框。

3. 迁入 `kit_mutations` 自带选择 UI
   - `kit_mutations` 文本里有 “You can select up to 10 Mutators for this game.”，说明原包有合作因子选择 UI 设计。
   - 但这条路径需要接入更多 UI/触发器状态，并处理和 7vs1 指挥官选择、任务初始化、敌方 AI 的冲突。
   - 当前不建议作为第一阶段。

当前建议：先保留 `Attribute011` 作为单因子兼容入口，把正式多选建立在银行注入上。等 69 个 id 分批进图验证稳定后，再决定是否做外部 UI 或大厅多槽位。
