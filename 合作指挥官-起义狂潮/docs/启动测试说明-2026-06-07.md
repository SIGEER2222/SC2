# 启动测试说明 - 2026-06-07

## 当前可直接用的脚本

- `scripts/launch-7vs1-coop-test.ps1`
  - 把选定 `_7vs1` 地图和 `Mods/7vs1` 运行库安装到 SC2 live 目录，然后启动地图。

- `scripts/capture-7vs1-ingame-smoke.ps1`
  - 自动启动后等待一段时间，抓图并记录 `ScriptError` / `Crash` / `Alerts` / `login_required`。

## 目标目录直接手动开图

在 `E:\Code\MyMod\SC2\合作指挥官-起义狂潮` 根目录执行：

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File .\scripts\launch-7vs1-coop-test.ps1 `
  -MapSource "Maps\ttosh02_7vs1.SC2Map" `
  -LiveMapName "ttosh02_7vs1.SC2Map" `
  -Commanders TerranRaynor
```

换图时只改 `MapSource` 和 `LiveMapName`，例如：

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File .\scripts\launch-7vs1-coop-test.ps1 `
  -MapSource "Maps\thanson01_7vs1.SC2Map" `
  -LiveMapName "thanson01_7vs1.SC2Map" `
  -Commanders TerranRaynor
```

## 自动烟测

在目标目录根目录执行：

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File .\scripts\capture-7vs1-ingame-smoke.ps1 `
  -MapSource "Maps\ttosh02_7vs1.SC2Map" `
  -LiveMapName "ttosh02_7vs1.SC2Map" `
  -Commanders TerranRaynor
```

## 判据

- 启动脚本能拉起地图，只说明安装和启动链条通了。
- `login_required` 只说明没有新增启动级阻塞，不代表已经真正进图。
- 真正验证通过仍然要看：
  - 是否进入地图。
  - 开局指挥官单位是否正确。
  - 地图初始化器是否运行。
  - 敌方进攻 / 发展 / 运输 / 护送逻辑是否还在。
