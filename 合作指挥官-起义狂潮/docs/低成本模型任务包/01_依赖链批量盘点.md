# 任务：依赖链批量盘点

## 参数

- `{{BATCH_ID}}`：本批次名称。
- `{{TARGETS_FILE}}`：UTF-8 文本，每行一个地图或 Mod 路径。
- `{{EFFECTIVE}}`：`true` 或 `false`。
- `{{COMMANDERS}}`：逗号分隔的指挥官 ID；不需要时留空。

## 目标

机械地运行依赖解析，汇总加载顺序、缺失边界和旧依赖替换。不要判断应该修改哪个依赖。

## 执行约束

1. 源文件只读。
2. 输出目录：
   `合作指挥官-起义狂潮/docs/低成本模型产物/dependency-inventory/{{BATCH_ID}}/`
3. 每个目标保存独立 JSON，不合并或删减原始输出。
4. 工具返回非零时仍保存 stdout、stderr 和退出码，然后继续下一个目标。

## 命令

从仓库根目录执行：

```powershell
$tool = "合作指挥官-起义狂潮/scripts/sc2-editor-toolkit/cli.mjs"
node $tool inspect "<target>" --format json
```

当 `{{EFFECTIVE}} = true`：

```powershell
node $tool inspect "<target>" --effective --commander "{{COMMANDERS}}" --format json
```

## 输出

### `raw/<序号>.json`

工具原始 JSON。另存同名 `.meta.json`：

```json
{
  "target": "",
  "command": "",
  "exitCode": 0,
  "stderr": ""
}
```

### `dependency-summary.csv`

列：

```text
target,mode,profile,commanders,loadOrderCount,issueCount,errorCount,warningCount,incompleteCount,completeGuess
```

`completeGuess` 只能按以下机械规则填写：

- 存在 `external/missing/legacy/needs-selection` 边时为 `false`。
- 否则为 `true`。
- 工具异常时为空。

### `issues.md`

按目标列出所有 issue 和以下状态边：

```text
external
missing
legacy
needs-selection
replaced
```

不要写根因结论。需要判断时写 `NEEDS_SENIOR_REVIEW`。

### `run-summary.json`

记录批次、输入数量、成功数量、非零退出数量、不完整数量、工具异常数量和产物路径。

## 停止条件

- 单个目标异常：记录后继续。
- 工具文件不存在或连续 3 个目标发生同类工具异常：停止批次并写明阻塞。
- 不允许使用 `--allow-incomplete` 隐藏不完整状态。
