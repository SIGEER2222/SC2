# 任务：验证日志与文档陈旧项盘点

## 参数

- `{{BATCH_ID}}`：本批次名称。
- `{{CHECKS}}`：逗号分隔，可选：
  `toolkit,galaxy-checker,web-launcher,skill,doctor,diff-check,route,docs`
- `{{EXPLICIT_FILES}}`：需要运行 `check --run` 时的显式文件列表；可为空。

## 目标

运行无交互静态检查、保存完整日志，并机械查找文档中的易过期事实。不要修代码或文档。

## 执行约束

1. 源文件只读。
2. 输出目录：
   `合作指挥官-起义狂潮/docs/低成本模型产物/validation-doc-audit/{{BATCH_ID}}/`
3. 不使用 `check --changed`，脏工作区必须传 `{{EXPLICIT_FILES}}`。
4. 不启动游戏，不重启进程。
5. 每条命令保存 stdout、stderr、退出码和耗时。

## 文档扫描

在 `AGENTS.md`、`.codex/skills/sc2-workflow` 和
`合作指挥官-起义狂潮/docs` 中搜索以下候选：

- 固定测试数量，例如 `132 个测试`、`15 条规则`。
- 已不存在的路径。
- 重复出现的完整命令块。
- 已实现但仍列在“已知限制/后续演进”的项目。
- 同一工具在多个文档中的互相矛盾描述。

只能输出候选，不能自动修改。

## 输出

### `raw/<check>.stdout.txt`

每个检查的完整输出；同时保存 stderr 和 meta JSON。

### `validation-summary.csv`

```text
check,command,exitCode,durationMs,passCount,failCount,errorSummary,rawOutput
```

无法机械提取计数时留空，不估算。

### `stale-doc-candidates.csv`

```text
category,file,line,text,reason
```

`category` 只能使用：

```text
fixed-count
missing-path
duplicate-command
implemented-but-listed
contradiction
```

### `needs-senior-review.md`

列出非零检查、doctor error、缺失路径、矛盾描述和无法解析的测试输出。

### `run-summary.json`

记录请求检查、实际执行检查、成功/失败数量、文档候选数量和工具异常。
