# 低成本模型任务包

这里的任务专门拆分高重复、高输出量、低判断需求的工作。每个任务文件都可以整份交给
便宜模型，只需要替换文件开头的 `{{参数}}`。

## 适合委派

| 任务 | 文件 | 主要消耗 |
|---|---|---|
| 批量解析地图/Mod 依赖链 | `01_依赖链批量盘点.md` | 大量 CLI 输出与表格整理 |
| 批量检查生产链和技能 | `02_单位诊断矩阵.md` | 多单位重复运行与 issue 汇总 |
| 收集 Galaxy 静态错误 | `03_Galaxy错误批量清单.md` | 完整日志阅读、去重和归档 |
| 批量追踪/对比 Catalog | `04_Catalog追踪与环境对比.md` | 多 ID、多环境 JSON 整理 |
| 中文名称反查内部 ID | `05_本地化名称反查候选.md` | 大范围文本搜索与候选表 |
| 枚举 MPQ 地图结构 | `06_MPQ地图结构清单.md` | 大量归档文件名和元数据 |
| 运行测试并盘点文档陈旧项 | `07_验证日志与文档盘点.md` | 长测试日志和重复文档扫描 |

机器可读索引见 `task-manifest.json`。

## 统一规则

1. 默认只读源文件。只允许在
   `合作指挥官-起义狂潮/docs/低成本模型产物/{{任务ID}}/` 下创建结果。
2. 不修改 GameData、Galaxy、地图、Mod、配置、Skill 或源码。
3. 不运行 `git add`、`git commit`、`git push`、reset、checkout 或清理命令。
4. 保存原始命令、退出码和完整原始输出，摘要不能替代原始证据。
5. 不把 `complete: false`、外部依赖、工具异常或空结果解释为“没有问题”。
6. 不判断哪个包应该被修改，不提出直接 XML/Galaxy 补丁。
7. 遇到需要判断的内容标为 `NEEDS_SENIOR_REVIEW`，继续处理其他机械项目。
8. 结果必须包含 `run-summary.json`，记录开始时间、结束时间、输入范围、成功数、失败数、
   不完整数和工具异常数。

## 不应委派

以下工作保留给高能力模型：

- 决定依赖顺序、ID 所有权和最终修复层级。
- 修改 XML/Galaxy、解析器、合并语义或启动器。
- 判断 checker 报错是否可接受或是否属于跨 Mod 已知边界。
- 解释复杂 Requirement、运行时变量传播和间接函数调用。
- 进图测试、进程重启、ScriptError 根因分析。
- 选择回归测试设计、评审补丁和最终提交。

## 推荐派单方式

一次只给便宜模型一个任务文件和一个明确批次。例如：

```text
执行 02_单位诊断矩阵.md。
{{BATCH_ID}} = raynor-core-01
{{CASES_FILE}} = E:\...\raynor-unit-cases.tsv
不要修改源文件，只写任务指定的产物目录。
```

大批量工作按指挥官、地图族或 20-50 个 ID 分批，避免一次输出过大后丢失证据。
