# 任务：单位生产与技能诊断矩阵

## 参数

- `{{BATCH_ID}}`：本批次名称。
- `{{CASES_FILE}}`：UTF-8 TSV 文件。

TSV 列：

```text
caseId	target	effective	commander	unit	producer	expectedAbilities
```

- `effective` 为 `true/false`。
- `producer` 可为空，表示自动发现。
- `expectedAbilities` 使用逗号分隔。

示例仅用于说明格式：

```text
raynor-marine	E:\path\Target.SC2Map	true	TerranRaynor	MarineRaynor	BarracksRaynor	SuperStimpackMarineRaynor
```

## 目标

重复运行 `diagnose-unit`，输出可筛选的问题矩阵。不要直接阅读 XML 后自行判断修复方式。

## 执行约束

1. 源文件只读。
2. 输出目录：
   `合作指挥官-起义狂潮/docs/低成本模型产物/unit-diagnostic-matrix/{{BATCH_ID}}/`
3. 每个 case 保存完整 JSON 和命令元数据。
4. 不使用 `--allow-incomplete`。依赖不完整必须保留为失败证据。

## 命令

基础命令：

```powershell
$tool = "合作指挥官-起义狂潮/scripts/sc2-editor-toolkit/cli.mjs"
node $tool diagnose-unit "<target>" --unit "<unit>" --format json
```

按非空列追加：

```text
--producer "<producer>"
--expect-ability "<expectedAbilities>"
--effective --commander "<commander>"
```

## 输出

### `raw/<caseId>.json`

保存工具原始 JSON。另存 `<caseId>.meta.json`，包含命令、退出码和 stderr。

### `unit-summary.csv`

列：

```text
caseId,target,commander,unit,producer,status,complete,hasErrors,parentChain,staticAbilityCount,effectiveAbilityCount,productionCandidateCount,selectedProductionAbility,selectedCommand,buttonVisible,runtimeEventCount,issueCount,exitCode
```

### `issue-counts.csv`

按 `severity + code` 聚合：

```text
severity,code,count,caseIds
```

### `needs-senior-review.md`

只列：

- `complete: false`
- `UNIT_PARENT_UNRESOLVED`
- `UNIT_PARENT_CIRCULAR`
- `PRODUCER_PARENT_UNRESOLVED`
- `PRODUCER_PARENT_CIRCULAR`
- `STATIC_RUNTIME_DIVERGENCE`
- 工具异常

不得提出补丁。每项附 caseId 和原始 JSON 路径。

### `run-summary.json`

记录总 case 数、ok/incomplete/error 数、非零退出数、工具异常数和 issue code 数量。

## 停止条件

- 单 case 失败不停止。
- JSON 无法解析时保存原始 stdout，标为工具异常并继续。
- 连续 3 个 case 都因同一 CLI 异常失败时停止批次。
