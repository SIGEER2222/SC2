# 任务：本地化名称反查内部 ID 候选

## 参数

- `{{BATCH_ID}}`：本批次名称。
- `{{NAMES_FILE}}`：UTF-8 文本，每行一个中文或英文显示名称。
- `{{SEARCH_ROOTS}}`：分号分隔的只读搜索目录。

推荐根：

```text
合作指挥官-起义狂潮
其他mod/SC2GameData
```

## 目标

从本地化文本和 Catalog XML 中提取内部 ID 候选，减少高能力模型阅读海量搜索结果的
消耗。只输出候选，不决定唯一正确 ID。

## 搜索范围

优先搜索：

- `GameStrings.txt`
- `ObjectStrings.txt`
- `TriggerStrings.txt`
- `ButtonData*.xml`
- `AbilData*.xml`
- `UpgradeData*.xml`
- `RequirementData*.xml`
- `UnitData*.xml`

使用 `rg -n -F` 做固定字符串搜索；`rg` 不可用时才使用 PowerShell `Select-String
-SimpleMatch`。

## 执行约束

1. 源文件只读。
2. 输出目录：
   `合作指挥官-起义狂潮/docs/低成本模型产物/localized-name-candidates/{{BATCH_ID}}/`
3. 每个名称保留最多 200 条原始命中；超过时记录总数并截断。
4. 不根据相似度自行改写搜索词，除非额外执行“去首尾空格”和“不区分大小写”两种固定
   变体。

## 输出

### `raw/<序号>.txt`

保存该名称的全部允许范围内命中。

### `name-candidates.csv`

```text
query,matchedText,internalId,catalogHint,file,line,evidence,confidence
```

`confidence` 只能使用：

- `exact-key`：本地化键直接包含内部 ID。
- `exact-value`：值完全匹配显示名称。
- `xml-nearby`：XML 同一条目附近出现匹配文本键。
- `weak`：只有文本命中，无法恢复 ID。

`catalogHint` 只能从文件名或键前缀机械推断为
`Unit/Button/Abil/Upgrade/Requirement/Unknown`。

### `unmatched.txt`

无命中的输入名称，每行一个。

### `needs-senior-review.md`

列出候选超过 10 个、跨多个 catalog、仅 weak 命中或同一显示名映射多个 ID 的名称。

### `run-summary.json`

记录查询数、命中数、未命中数、候选总数、截断数量和搜索根。

## 禁止事项

- 不修改本地化文件。
- 不把候选 ID 写回地图。
- 不声称某个 ID 已确认，除非是单一 `exact-key`，即便如此也只标为候选。
