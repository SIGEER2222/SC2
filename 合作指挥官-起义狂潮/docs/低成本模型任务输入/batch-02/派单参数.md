# batch-02 派单参数

每个任务执行后必须运行 `scripts/low-cost-batch-validator/cli.mjs`，只有退出码 0 才能标记
完成。源文件只读，产物写入 `docs/低成本模型产物/<任务 id>/batch-02/`。

1. `01_依赖链批量盘点.md`
   - declared：`TARGETS_FILE=01-targets-declared.txt`，`EFFECTIVE=false`
   - effective：`TARGETS_FILE=01-targets-effective.txt`，`EFFECTIVE=true`，
     `COMMANDERS=TerranRaynor`
2. `02_单位诊断矩阵.md`
   - `CASES_FILE=02-unit-cases.tsv`
3. `03_Galaxy错误批量清单.md`
   - `BASE_DATA_DIRS_FILE=03-base-data-dirs.txt`
   - `SYMBOL_ROOTS_FILE=03-symbol-roots.txt`
4. `04_Catalog追踪与环境对比.md`
   - `CASES_FILE=04-cases.tsv`
5. `05_本地化名称反查候选.md`
   - `NAMES_FILE=05-names.txt`
   - `SEARCH_ROOTS=合作指挥官-起义狂潮;其他mod/SC2GameData`
6. `06_MPQ地图结构清单.md`
   - `MAPS_FILE=06-maps.txt`
7. `07_验证日志与文档盘点.md`
   - `CHECKS=toolkit,galaxy-checker,skill,doctor,diff-check,docs`
   - `EXPLICIT_FILES` 留空

任务 03 必须保存完整 stdout/stderr/meta；`XLIB_DISCOURAGED_NATIVE` 是策略 warning，
不能计入编译 error。任务 02 必须验证 `expectedAbilities`，不能只检查生产按钮。
