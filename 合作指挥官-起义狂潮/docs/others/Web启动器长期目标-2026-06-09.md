# Web 启动器长期目标

## 当前目标

把临时 WinForms 启动器升级为本地 Web 启动器，用来选择指挥官、地图、精通/威望加点、因子并启动游戏。第一阶段不重写已有启动链路，仍复用 `scripts/launch-7vs1-coop-test.ps1`，Web 只负责选择、校验、展示和桥接。

## 数据来源

- 指挥官、威望、精通：`Shared/CommanderPower/commander-power-metadata.json`
- 地图：`Maps/*_7vs1.SC2Map`
- 可注入因子白名单：`scripts/launch-7vs1-coop-test.ps1` 内 `Set-CampaignXCoreMutatorPreset` 的 `$allowedMutators`
- 因子名称与描述：`Mods/kit_mutations.SC2Mod/zhCN.SC2Data/LocalizedData/GameStrings.txt`
- 因子图标引用：`Mods/kit_mutations.SC2Mod/Base.SC2Data/GameData/Mutators.xml`
- 额外资源引用：`PreloadAssetDB.txt`、`assets.txt`

## 阶段规划

### 阶段 1：可用 Web 启动器

- 新增 `scripts/start-7vs1-web-launcher.ps1`
- 本地 HTTP 服务提供 `/api/bootstrap` 与 `/api/launch`
- 静态页面位于 `web-launcher/`
- 支持单指挥官、单地图、威望解锁/当前威望、6 个精通槽、因子多选、测试安装不启动
- 启动仍委托 `launch-7vs1-coop-test.ps1`

### 阶段 2：资源索引

- 从文本/XML 中生成浏览器可读的资源索引
- 先展示文字、图标路径、音效路径引用
- 不在第一阶段强行转换 DDS 或音频

### 阶段 3：浏览器资源转换

- 确认 DDS 图标和音效的真实来源
- 如果仓库内已有可转换文件，生成 `web-launcher/assets/` 下的 PNG/OGG/MP3
- 如果资源只存在于 SC2 CASC/编辑器环境，记录导出流程并让脚本消费导出产物

### 阶段 4：因子选择体验

- 多选、搜索、分类、预设保存
- 结合当前 bank 注入方式生成组合
- 后续可以加入“随机 N 个因子”“挑战包”“最近使用组合”

## 当前边界

- 第一版 Web 启动器是本地开发工具，不做公网服务。
- 第一版只保证资源引用完整，不保证图标/音效已经转成浏览器可播放格式。
- `ttosh02_7vs1` 等特殊图如果仍有指挥官限制，启动脚本是最终约束来源。
