## Package Type

`Maps/67vs1_2023.SC2Map` is a map package, not a mod. It has:

- `DocumentInfo`
- `MapInfo`
- `MapScript.galaxy`
- `Objects`
- `t3Terrain.xml`
- `Base.SC2Data/GameData/*.xml`
- localized text under `zhCN.SC2Data`, `zhTW.SC2Data`, `enUS.SC2Data`, and `koKR.SC2Data`

The top-level `DocumentInfo` declares:

```xml
<ModType>
    <Value>Interface</Value>
</ModType>
```

The original unpacked map depended on:

```text

file:Mods\starcoop/commanders/arcturusmengsk.sc2mod
file:Mods\starcoop/commanders/egonstetmann.sc2mod
```

Those dependencies are mod packages. The local working copy now resolves them from unpacked source directories instead of the Battle.net cache:


## Local Source Layout

The 2023 7vs1 map and its current coop commander dependencies have been unpacked into the workspace for local editing:

- `Maps/67vs1_2023.SC2Map` - the editable 2023 7vs1 map package.
- `Mods/StarCoop/StarCoop.SC2Mod` - the main StarCoop dependency.
- `Mods/StarCoop/Commanders/ArcturusMengsk.SC2Mod` - Mengsk commander dependency used by the map.
- `Mods/StarCoop/Commanders/EgonStetmann.SC2Mod` - Stetmann commander dependency used by the map.
- `Mods/VoidMulti.SC2Mod` - local official VoidMulti source mirror used by the launch tooling.

The unpacked official mirrors are also available under:

```text
游戏数据/官方SC2原始文本镜像/mods/
```

These source directories are intentionally ignored by git because they are large extracted SC2 packages and local working copies. The tracked launch script can use the local mirror first and fall back to the old Downloads mirror if the workspace mirror is absent.

In this repository, the separate 7vs1 coop commander test runtime is still under `Mods/7vs1/`, especially `CoopZeroPop.SC2Mod` and `CommanderCatalog.SC2Mod`.

## Naming Note

The editable directory is named `67vs1_2023.SC2Map`, not `*_7vs1.SC2Map`, so it does not get picked up by the existing campaign-hybrid variant validator. The existing `*_7vs1.SC2Map` directories are transformed campaign map variants with the local 7vs1 coop test runtime injected.
