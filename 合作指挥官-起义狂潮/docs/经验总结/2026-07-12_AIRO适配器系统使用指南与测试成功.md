# AIRO 适配器系统使用指南与测试成功

## 概述

AIRO 适配器系统（AI Reborn Overdrive）是将 7vs1 合作指挥官系统与 RevolutionOverdrive 战役地图结合的桥梁模块，实现原版战役地图中单位自动替换为对应指挥官单位的功能。

## 模块架构

```
Mods/AIRO/
├── AIROAdapter.SC2Mod/          # 核心调度器
│   ├── Base.SC2Data/
│   │   ├── LibAIROAdapter.galaxy
│   │   ├── LibAIROAdapter_h.galaxy
│   │   ├── LibAIROAdapterInterface_h.galaxy
│   ├── ComponentList.SC2Components
│   ├── DataCenter.json
│   ├── DocumentInfo
│   └── DocumentHeader
└── Adapters/                    # 各指挥官适配器
    ├── ZergKerriganAdapter.SC2Mod/
    ├── ProtossArtanisAdapter.SC2Mod/
    ├── TerranRaynorAdapter.SC2Mod/
    └── ...（共 8 个现有适配器）
```

## 核心功能

1. **启动时清理**：在 `gt_Init03Units` 执行后清理玩家1起始位置半径25格内的原版 Terran 单位
2. **事件驱动替换**：监听玩家1单位创建事件，自动替换为对应指挥官单位
3. **指挥官映射**：定义原版单位到对应指挥官单位的映射表
4. **统一接口**：`libAIROAdapterInterface_*` 系列函数统一各适配器实现

## 使用方法

### 1. 启动游戏

```powershell
cd "E:\Code\MyMod\SC2\合作指挥官-起义狂潮"
.\scripts\airo\launch-airo-campaign.ps1 -Commander "ZergKerrigan" -MapName "traynor01.SC2Map"
```

参数：
- `-Commander`：要启动的指挥官（支持全部19个7vs1指挥官）
- `-MapName`：要启动的 AIRO 地图（位于 `Maps/AIRO/`）
- `-NoLaunch`：只进行同步不启动游戏
- `-DryRun`：显示计划但不执行操作
- `-SkipWait`：启动后不等游戏就绪直接退出

### 2. 验证结果

检查以下项目：
1. 起始位置：只有指挥官的单位，没有原版 Terran
2. 空投/任务/奖励单位：自动替换为对应指挥官单位
3. `XMRuntimeDebug` Bank 状态：确认 `Commander`、`TownHallUnit`、`WorkerUnit`、`SecondUnit` 已正确设置
4. ScriptError 无 AIRO 相关错误

## 添加新指挥官适配器

1. 复制现有适配器（如 `ZergKerriganAdapter.SC2Mod`）为新的名称
2. 修改 `DataCenter.json` 中的 `id`
3. 修改 `LibAIROAdapter_CommanderName.galaxy` 中的单位映射表
4. 更新 `airo-dependencies.json` 中的 `adapterMapping`

## 关键注意事项

1. **绝对不要手动修改 `AIROAdapter.SC2Mod/Base.SC2Data/` 下的文件** — 这些文件已经过精心调优，手动修改可能导致游戏崩溃！
2. **Git restore 是救星**：如果不小心改坏了，用 `git restore Mods/AIRO/AIROAdapter.SC2Mod/Base.SC2Data/LibAIROAdapter.galaxy` 恢复原状！
3. **变量声明位置**：Galaxy 要求所有变量声明必须在函数开头！不能在函数体中间声明变量！
4. **UnitGroup 遍历**：必须使用 `UnitGroupLoopBegin()` / `UnitGroupLoopStep()` / `UnitGroupLoopEnd()`，不能用 `UnitGroupPickRandomUnit()` 加参数（会语法错误）！
