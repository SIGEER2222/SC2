## 任务信息

- **任务耗时**: 约 13 分钟

## 任务内容

继续之前会话的"顶部技能面板移植"任务。用户反馈 Reborn 地图上 Raynor 指挥官的顶部技能面板完全不显示。

### 诊断

通过 RuntimeProbe Bank 文件系统和 SC2 内部 API 对接方案验证：

1. **GlobalCastingPanel holder 检查**: 扩展 RuntimeProbe 添加 `ScanUI` 函数，通过 `DialogControlHookupStandard(c_triggerControlTypePanel, "UIContainer/FullscreenUpperContainer/GlobalCastingPanel")` 检查 holder 是否存在
2. **cutscene 文件缺失**: `TerranCasterPanelTemplate` (Coop_GlobalCastingTemplates.SC2Layout 行 1479) 引用 `Cutscenes/UI_TerranCastingPanel.SC2Cutscene`，该文件仅存在于 CMRE mod 中，RebornBridge 中缺失
3. **ScriptError 分析**: 之前会话中 `libVCUI_gt_PU_GPBirthFinished_Func` 的 `DialogControlSetPropertyAsBool` triggerControl=0 错误与 cutscene 加载失败相关

### 修复

1. **复制 cutscene 文件**: 从 `CMRE_Core_Triggers.SC2Mod` 复制 `ui_terrancastingpanel.sc2cutscene` (5935 字节 XML) 到 `RebornBridge.SC2Mod/Base.SC2Data/Cutscenes/`
2. **补充提交 UI 模板**: 提交之前会话创建的 `Coop_GlobalCastingTemplates.SC2Layout` (86227 字节)
3. **扩展 RuntimeProbe**: 添加 `libRuntimeProbe_gf_ScanUI()` 函数采集 UI 控件状态到 `probe_ui` Bank section
