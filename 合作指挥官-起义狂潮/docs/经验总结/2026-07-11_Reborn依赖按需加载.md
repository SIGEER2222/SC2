# Reborn 依赖按需加载 — Alenger adapter 从硬编码改为 generated galaxy

> 日期: 2026-07-11
> Commit: 5d8227a
> 关联: 2026-07-11-reborn-dependency-on-demand-design.md

## 问题

CoreRuntime 的 `LibE0EAE146_AdapterBootstrap.galaxy` 硬编码 include 全部 11 个 Alenger adapter（LibA1ADAPTER ~ LibA13ADAPTER），导致 24 个 Alenger mod 必须全量加载，DocumentHeader 依赖数达 37 个，游戏加载缓慢甚至崩溃。

## 解决方案

将 AdapterBootstrap 从 CoreRuntime 移除，改为 RebornMapAdapter 通过 generated galaxy 按需加载：

1. **CoreRuntime 清理**: 删除 `LibE0EAE146_AdapterBootstrap.galaxy` 和 `_h.galaxy`，从 `LibE0EAE146.galaxy` 移除 include 和 InitLib 调用
2. **RebornMapAdapter 承接**: 新增 `LibRebornAdapter_AlengerBootstrap_h.galaxy` 静态头文件，`RebornMapAdapter.galaxy` include 头文件 + 实现文件，`OnAfterUnitsInit` 调用 `libRebornAdapter_AlengerBootstrap_InitLib()`
3. **generated galaxy**: `bootstrapGenerator.mjs` 的 `generateAlengerBootstrap` 函数根据选中指挥官生成对应的 `LibRebornAdapter_AlengerBootstrap.galaxy`（空壳或含 adapter include）
4. **CLI wrapper**: `alengerBootstrapCli.mjs` 供 PowerShell launcher 调用 Node.js 生成 galaxy 文件
5. **launcher-plan.ps1**: L2 层改为按需 Alenger（commanderToAlenger 映射），Campaign 依赖改为按地图（mapCampaigns）
6. **launch-reborn-commander.ps1**: 添加 AlengerBootstrap 生成调用 + Alenger mod 按需同步
7. **config-validation.ps1**: 允许 Alenger 系列指挥官不在 commander-units-mapping 中（通过 commanderToAlenger 归一化匹配）

## 关键经验

### 1. galaxy include 实现文件必须被显式 include

**问题**: RebornMapAdapter.galaxy 只 include 了头文件 `LibRebornAdapter_AlengerBootstrap_h`，但头文件只声明函数，没有定义。生成的实现文件 `LibRebornAdapter_AlengerBootstrap.galaxy` 虽然在 map Base.SC2Data 中，但没有被任何 galaxy 文件 include，导致编译器找不到 `libRebornAdapter_AlengerBootstrap_InitLib()` 的定义，游戏崩溃（无 ScriptError，直接 crash）。

**修复**: 在 RebornMapAdapter.galaxy 中添加 `include "LibRebornAdapter_AlengerBootstrap"`（实现文件）。

**规则**: galaxy include 头文件只引入函数声明，实现文件必须被显式 include 才能让编译器找到函数定义。这与 C/C++ 类似，但 galaxy 没有自动链接机制。

### 2. galaxy include 解析顺序

map Base.SC2Data 优先于 mod 依赖链。RebornMapAdapter.galaxy 在 mod 中，但其副本被复制到 map Base.SC2Data。编译时使用 map 中的副本，其 include "LibRebornAdapter_AlengerBootstrap" 会解析到同在 map Base.SC2Data 中的生成文件。

### 3. Alenger commander 归一化

commander ID 格式可能是 `TerranAlenger3` 或 `Alenger3`，但 `commanderToAlenger` 的 key 使用 `Alenger3` 格式。需要剥离种族前缀（Terran/Zerg/Protoss）进行匹配。

### 4. PowerShell 5.1 大小写不敏感

`$Plan` 参数与 `$plan` 变量在 PS 5.1 中冲突，需用 `$launcherPlan`。

### 5. config-validation 需要支持多种 commander 来源

Alenger 系列指挥官不在 `commander-units-mapping.mappings` 中（没有 CommanderUnits mod），而是通过 `alenger-mods.commanderToAlenger` 解析。验证逻辑需要允许这种情况。

## 验证结果

- 依赖数: Raynor 13（原 37），Alenger3 15（原 37）
- 进图测试: Raynor + Alenger3 均通过（exit 0）
- ScriptError: 仅有已有的运行时触发器警告（点位、科技参数），非本次改动引入
- 单元测试: 98 个全部通过
