## 8. 关键技术经验

- **galaxy 嵌套 include 限制**：galaxy 文件复制到地图 `Base.SC2Data` 后，嵌套 include 无法解析；应通过 mod 依赖链加载 CoreRuntime galaxy 文件。7vs1 参考地图 `Base.SC2Data` 为空，通过 mod 依赖链加载。
- **战役图初始化链**：`gt_Initialization_Func` 通过 `TriggerExecute` 串行调用 Init01-Init07（科技、玩家、单位、音乐、环境、难度、帮助）。注释 `libSwaC_gf_ULoadCampaignData` 会导致初始化在第一个 `TriggerExecute` 前中断，地图呈空白状态。
- **SwarmStory 安全限制**：`SwarmStory.SC2Campaign` 原生函数在非战役启动时调用会失败，导致触发器失败和卡加载。
- **数据空间不替代依赖规则**：数据空间是 Catalog XML 的组织和入口机制，不改变 SC2 依赖加载顺序，不自动解决同 ID 覆盖。
- **Alenger mod 路径硬编码**：Alenger 系列 mod 必须放在 `Mods/Alenger/` 子目录（依赖路径硬编码了 `file:Mods\Alenger\xxx`）。
- **CommanderAch 实例缺失**：XM mod 的 `libE0EAE146_gf_InitializeBase` 使用 `UserDataGetUnit` 读取 `Alenger3`，7vs1 框架下需在 `Alenger3Adapter.SC2Mod` 中添加 `Alenger3` 实例映射。
