# Neuro 7vs1 主循环闭环修复

- 任务类型：SC2 Galaxy + Neuro 运行时闭环修复 + 进图验证
- 时间戳：2026-07-12
- 分支：fix_003

## 任务内容

逐项推进 Neuro 阻塞问题，优先修复 7vs1 `execute_actions_map` 主循环未跑通。

## 根因

1. **MapInit 中 Wait 不恢复**：EFA `InitMap`/`CreateBank` 里的 `Wait` 会堵 7vs1 MapInit 队列。
2. **`bankwriteallowed` 死锁**：`execute_actions_global` 在发 map 事件前保持 `false`，导致 `RegisterActions`/`create_action` 卡在 while-Wait。
3. **`TriggerSendEvent("execute_actions_map")` 在注入场景无响应**：global 已执行到 `debug_global_before_map=1`，但 bridge 监听器不触发。
4. **战役 Victory 面板 TriggerEnable 对 null 硬崩**：7vs1 无 `libCamp_gt_TS_VSScreen*`。

## 修复

### NeuroIntegration (`tools/SC2-Neuro-WoL-Integration`)

- 去掉 MapInit 阻塞 Wait；CreateBank 后异步启动 global
- global 循环：恢复 `bankwriteallowed`；去掉启动期 Wait；写 `debug_global_*`
- 新增共享 `libEFA54406_gt_MapActionHook`，优先 `TriggerExecute` 调 map 侧
- Victory 面板 `TriggerEnable` 加 null 保护

### NeuroBridge7vs1

- InitLib 注册 map 执行触发器并挂到 `libEFA54406_gt_MapActionHook`
- map 循环首轮注册 7vs1 action；回抛 global 用 `TriggerExecute`
- `train_unit`：`Marine`→`MarineRaynor`，走 `BarracksTrainRaynor` / `CommandCenterTrainRaynor` 索引扫描

### 启动与依赖

- `neuro-dependencies.json` / `neuro-7vs1-galaxy-manifest.json`
- launch 脚本读取闭包事实、自动 mock、注入 bank/galaxy
