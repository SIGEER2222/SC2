# Galaxy 聊天指令框架 + 皮肤/播报员切换经验

## 任务背景
在 AbathurHeartTest_unpacked 测试地图中实现聊天指令，用于：
1. 运行时切换单位皮肤（PlayerSetSkin）
2. 解锁 D.Va 播报员奖励（PlayerAddReward）

## SC2 API 限制（重要）

### 原生环境（无 mod）可调用
- `PlayerSetSkin(player, skinCollectionID)` - 实时切换玩家所有单位皮肤
- `PlayerApplySkin(player, skinID, apply)` - 应用/取消单个皮肤
- `PlayerAddReward(player, rewardID)` - 解锁奖励（播报员/皮肤/控制台等）
- `PlayerHasReward(player, rewardID)` - 检查是否已解锁

### mod 环境下无权调用（重要！）
当 mod 替换了 NativeLib 时，以下 native 函数会报 `出现触发器错误：无权调用'XXX'`：
- `PlayerSetSkin` - 无权调用
- `PlayerSetCommander` - 无权调用（Violets mod 自身也会触发此错误）
- `PlayerAddReward` - 无权调用（本次踩坑）
- `TriggerDebugOutput` - 不可用（改用 `TextTagCreate` 显示可见文字）
- `PlayerSetPropertyInt` + `c_playerPropMinerals` - 不可用

### 替代方案
- **皮肤切换**：用 `libNtve_gf_ReplaceUnit(unit, newType, options)` 替换单位类型
  - 例如 `gf_ReplaceAllUnits("Zealot", "ZealotTaldarim")`
  - 参考 RevolutionOverdrive 的 Lib6B3CCD85.galaxy 实现
- **播报员/控制台**：mod 环境下运行时无法切换，只能退出地图后在收藏界面手动选择
- **调试输出**：用 `TextTagCreate` 在地图中央显示漂浮文字

### 运行时无法切换（SC2 引擎限制）
- **播报员（Announcer/VoicePack）**：SC2 没有 `PlayerSetAnnouncer` 等 native 函数
- **控制台皮肤（ConsoleSkin）**：SC2 没有 `PlayerSetConsoleSkin` 等 native 函数
- 这些只能在游戏开局前由玩家在收藏界面选择

### D.Va 资源清单
- **播报员**：`BlizzConDVa`（CVoicePack），奖励 ID：
  - `VoicePackTerranBlizzConDVa`（人族）
  - `VoicePackZergBlizzConDVa`（虫族）
  - `VoicePackProtossBlizzConDVa`（星灵）
- **单位皮肤**：不存在
- **控制台皮肤**：不存在

## 聊天事件 API
- `TriggerAddEventChatMessage(trigger, player, inText, exact)` - 注册聊天事件
  - `player`：-1=任意玩家，1-15=指定玩家
  - `inText`："" = 匹配所有消息，非空 = 部分匹配
  - `exact`：true=精确匹配，false=部分匹配
- `EventChatMessage(matchedOnly)` - 获取聊天消息内容
  - `matchedOnly`：true=只返回匹配部分，false=返回完整消息

## Galaxy 语法陷阱（本次踩坑）

### 1. 不支持 `string[N] x = { ... }` 数组初始化语法
```galaxy
// 错误：编译报"初始化变量时出错"
string[12] gv_skinPresets = { "Taldarim", "Blizzcon17", ... };

// 正确：先声明，在函数内逐个赋值
string[12] gv_skinPresets;
void InitLibs () {
    gv_skinPresets[0] = "Taldarim";
    gv_skinPresets[1] = "Blizzcon17";
    ...
}
```

### 2. const int 不能用作数组大小
```galaxy
// 错误：编译报"初始化变量时出错"
const int gv_c_Count = 12;
string[gv_c_Count] gv_array;  // 报错

// 正确：直接用字面量数字
const int gv_c_Count = 12;
string[12] gv_array;
```

### 3. StringFind 在函数体内直接调用可能报"语法错误"
```galaxy
// 报错：if (StringFind(lv_msg, " ", false) > 0) { 语法错误
// 即使先存到变量也报错：lv_pos = StringFind(lv_msg, " ", false); if (lv_pos > 0) {

// 可行方案：避免在函数内用 StringFind 找字面量空格
// 改用 StringCase 转大写后直接 == 比较，或用无参数指令
```

注：`gf_CommanderMatchesFilter` 中 `if (StringFind(identifier, filter, false) > 0)` 能编译通过
（参数都是变量），但聊天指令中 `StringFind(lv_msg, " ", false)` 字面量空格会报错。
推测 galaxy 编译器对字面量空格字符串 `" "` 在函数调用中有特殊处理问题。

### 4. 复杂条件表达式建议加内层括号
```galaxy
// 不推荐（虽然 line 222 的 (a) && (b) 形式能通过）
if (StringFind(a, b, false) > 0 && StringLength(a) == StringLength(b)) {

// 推荐
if ((StringFind(a, b, false) > 0) && (StringLength(a) == StringLength(b))) {
```

### 5. 函数定义顺序要求
galaxy 要求函数先定义后使用（不支持前向引用）。`InitLibs` 中调用的函数必须在 `InitLibs` 之前定义，或在 `InitLibs` 内部直接实现逻辑。

## 判定脚本改进经验（wait-for-game-ready.ps1）

### 问题：中文错误关键字未识别
原版 `ErrorKeywords` 只有英文，导致中文错误（如"参数类型同函数定义不匹配"）被漏判，
脚本错误地报告"无 ScriptError"。

### 修复方案
1. **添加中文 ErrorKeywords**（致命错误，exit 1）：
   - `参数类型同函数定义不匹配`
   - `脚本读取失败`
   - `函数已声明但尚未定义`
2. **新增 WarnKeywords**（运行时警告，非致命，exit 0 但报告）：
   - `出现触发器错误`
   - `无权调用`
3. **添加 Get-ScriptWarnings 函数**：加载完成时检查 WarnKeywords，
   报告 `ScriptError: Exists with runtime warnings (non-fatal): XXX`
4. **UTF-8 BOM 编码**：PowerShell 读取含中文的 .ps1 文件必须用 UTF-8 with BOM，
   否则中文会被当 GBK 解析导致关键字匹配失败

### 判定逻辑
- **exit 1（失败）**：Alerts.txt 出现后 20 秒宽限期内出现新的致命 ScriptError（匹配 ErrorKeywords）
- **exit 0（成功）**：Alerts.txt 出现 + 20 秒宽限期无新致命 ScriptError + 游戏进程存活
  - 可能有运行时警告（WarnKeywords），但非致命，报告但不退出
- **exit 2（超时）**：180 秒内未检测到 Alerts.txt

## 位置边界检查经验

### 问题：单位生成位置 y=-0.5 超出地图边界
`gf_SpawnAllMods` 计算的 block 起始 y 可能接近地图边界，
block 内部 `gf_SpawnModUnits` 用 `baseY - row*spacing` 计算位置时可能变成负数，
导致 `libNtve_gf_CreateUnitsWithDefaultFacing` 报 `无效的位置：'108,-0.5'`。

### 修复方案
在 `gf_SpawnModUnits` 调用 `CreateUnitsWithDefaultFacing` 前检查 y 坐标：
```galaxy
lv_pos = Point(baseX + (lv_col * spacing), baseY - (lv_row * spacing));
// 边界检查：避免生成在地图外（y < 1 时跳过，防止 ScriptError "无效的位置"）
if (PointGetY(lv_pos) < 1.0) {
    lv_skipped += 1;
}
else {
    libNtve_gf_CreateUnitsWithDefaultFacing(1, lv_unitType, c_unitCreateIgnorePlacement, 1, lv_pos);
    lv_created += 1;
}
```

## autoTest 自动测试触发器

### 设计
游戏加载后 5 秒开始，间隔 7 秒执行 7 个步骤，自动验证聊天指令：
- step 1 (5s): -test（验证聊天框架）
- step 2 (10s): -help（显示指令列表）
- step 3 (15s): -dva（仅打印提示，PlayerAddReward 不可用）
- step 4 (20s): -skintaldarim（ReplaceUnit 替换为 Taldarim 皮肤）
- step 5 (27s): -skinreset（还原）
- step 6 (34s): -skinblizzcon17（ReplaceUnit 替换为 Blizzcon17 皮肤）
- step 7 (41s): -skinreset（还原）

### 实现
```galaxy
trigger gt_autoTest;
int gv_autoTestStep = 0;
timer gv_autoTestTimer;

bool gt_autoTest_Func (bool testConds, bool runActions) {
    int lv_step;
    if (!runActions) { return true; }
    gv_autoTestStep = gv_autoTestStep + 1;
    lv_step = gv_autoTestStep;
    if (lv_step == 1) { gf_DebugPrint("[AUTO 5s] -test"); ... }
    else if (lv_step == 7) { ...; return true; }  // 最后一步不再重启定时器
    TimerStart(gv_autoTestTimer, 7.0, false, c_timeGame);  // 重启定时器
    return true;
}

void gt_autoTest_Init () {
    gv_autoTestTimer = TimerCreate();
    gt_autoTest = TriggerCreate("gt_autoTest_Func");
    TriggerAddEventTimer(gt_autoTest, gv_autoTestTimer);
    TimerStart(gv_autoTestTimer, 5.0, false, c_timeGame);  // 首次 5 秒
}
```

### 注意
- `TimerWindowDestroy(int)` 接收 int 而非 timer 类型，不要传 `gv_autoTestTimer`
- 最后一步完成后 `return true` 不再重启定时器，自然结束
