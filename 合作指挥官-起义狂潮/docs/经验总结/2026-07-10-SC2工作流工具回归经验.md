# SC2 工作流工具回归经验（2026-07-10）

## 1. Windows 下不要直接用 spawnSync 启动 npm.cmd

### 现象

`check --run` 能生成 `toolkit-tests` 动作，但执行结果为 `exit=null`。单独验证发现：

- `spawnSync("npm")` 返回 `ENOENT`。
- `spawnSync("npm.cmd")` 返回 `EINVAL`。
- `node <node目录>/node_modules/npm/bin/npm-cli.js` 正常。

### 固化

- Windows 下用当前 `node.exe` 直接执行 `npm-cli.js` / `npx-cli.js`。
- 执行结果保留 `executedCommand`、`executedArgs` 和 `spawnError`。
- 增加 Windows/非 Windows 命令解析回归测试。

## 2. 来源追踪必须加载目标 ID 之外的父条目

### 现象

真实追踪 `MarineRaynor` 时，工具已经加载包含 `Marine` 的依赖包，却仍报告
`unresolvedParent: Marine`。

### 根因

旧实现只把目标 ID 加入 `CatalogStore`。`parentChain` 查询时，父 ID 从未进入 store。

### 固化

- 对依赖链中的全部 Catalog 条目执行合并。
- 只对目标 ID 记录 definition history，避免扩大输出。
- 增加 `MarineX -> Marine` 父链完整性测试。
- 同时修复无 `GameData` 包返回未定义 `entries` 的异常。

## 3. 运行时函数抽取要同时覆盖精确函数名和包装函数

### 现象

正则可以命中 `libNtve_gf_TechTreeUnitAllow`，但可能漏掉原生
`CatalogFieldValueSet(...)`。

### 根因

旧正则强制函数名前必须存在额外前缀，因此只适合包装函数后缀匹配。

### 固化

- 先提取行内全部函数调用标识符。
- 接受与配置名完全相等或以后缀形式包装的函数名。
- 同一回归测试同时覆盖包装函数和精确原生函数。

## 结论

工具链错误不能只写进说明文档。每个可复现问题都应同时落到实现修复和回归测试，
确保下一次诊断能自动规避同类失败。

## 4. 不完整的环境对比不能返回成功

### 现象

`compare` 在左右依赖均不完整时仍返回 exit 0。自动化调用容易把“没有看到字段差异”
误判为“两个环境一致”。

### 固化

- 增加 `status: complete|incomplete|missing`。
- 依赖不完整默认返回 exit 1，只有显式 `--allow-incomplete` 才允许成功退出。
- 文本输出直接列出左右缺失依赖和 unresolved parent。
- 返回 `runtimeScanComplete`，明确空运行时修改列表不代表扫描覆盖完整。

## 5. 多根 Galaxy 扫描必须覆盖函数的实际实现 Mod

### 现象

只加入 CoreRuntime、CommanderBridge 和少量指挥官包作为 `--symbol-root` 时，
CoreRuntime/CoopZeroPop 仍报告 `XLIB_UNDEFINED_CROSS_REF`。这些符号并非缺失，而是
实际定义在 `CommanderUnits_Fenix`、`CommanderUnits_TychusXM`、
`CommanderUnits_Mengsk`、`CommanderUnits_Kerrigan` 等独立 Mod 中。

### 固化

- 批量扫描的 symbol roots 必须覆盖全部包含 Galaxy 实现的 7vs1 Mod，不能只列当前
  指挥官或公共运行时。
- 报跨库未定义前，先在整个仓库搜索函数定义，区分真实缺失和扫描边界遗漏。
- batch-02 补齐 53 个根目录后，CoreRuntime、CoopZeroPop、CommanderBridge 均为
  0 error。

## 6. Windows 下运行 Python Skill 校验要显式启用 UTF-8

### 现象

`quick_validate.py` 使用系统默认编码读取中文 `SKILL.md` 时，在 GBK 环境抛出
`UnicodeDecodeError`。

### 固化

- 调用前设置 `PYTHONUTF8=1`，确保项目内 UTF-8 Skill 文档可稳定读取。
- 编码失败属于校验器启动失败，不能据此判断 Skill 内容无效。
