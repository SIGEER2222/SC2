| 错误码 | 说明 |
|--------|------|
| `e_unexpectedBreak` | 多余的 `break` 语句 |
| `e_unexpectedComment` | **不支持 `/* */` 格式的注释块**，只能用 `//` |
| `e_unexpectedContinue` | 多余的 `continue` 语句（**Galaxy 不支持 continue**！） |
| `e_unexpectedDirective` | Galaxy 不支持预处理指令（无 `#include`、`#define` 等） |
| `e_unexpectedGoto` | 不支持 `goto` 语句 |
| `e_unexpectedNew` | 不支持 `new` 动态内存分配 |

## 常见错误快速诊断

### "参数个数不符" / "参数类型不符"
- 检查 native 函数签名（在 `natives.galaxy` 中查）
- 常见：`EventChatMessage()` 缺少 bool 参数 → 应为 `EventChatMessage(false)`
- 常见：`PlayerSetColorIndex(player, color, false)` 第三个参数必须是 bool

### "不允许隐式类型转换"
- Galaxy 不允许 int → fixed、fixed → int 隐式转换
- 必须用 `StringToInt`、`IntToString`、`FixedToInt` 等显式转换函数
- `text` 和 `string` 是不同类型，不能直接拼接
  - 错误：`"abc" + IntToText(1)`（text + string）
  - 正确：`"abc" + IntToString(1)`（string + string）

### "函数已声明但未定义"
- 函数声明了但没实现函数体
- 常见：在 header 文件声明了函数，但 galaxy 文件没实现

### "多余的 continue 语句"
- **Galaxy 不支持 continue**
- 必须用 if 块包裹后续逻辑

### "Galaxy 数组需要将数组尺寸放在类型后面"
- 错误：`int arr[10];`
- 正确：`int[10] arr;`

### "局部变量太大"
- 局部变量超过 32k-1 字节限制
- 解决：拆分函数，或改用全局变量

### "脚本太大"
- 单个 galaxy 文件过大（接近解析限制）
- 解决：拆分成多个 galaxy 文件，用 `include` 引入
- 项目经验：libE0EAE146.galaxy 接近解析限制，新功能应分到独立 Runtime 文件
