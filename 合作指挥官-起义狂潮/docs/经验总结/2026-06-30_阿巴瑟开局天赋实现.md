## 背景

实现阿巴瑟的两个开局天赋（与 WebUI `StartTalentMask` 对接）：
- Bit 0 (`AbathurStartBiomass`)：所有出生的战斗单位开局自带 50 层生物质

## 卡片 1：Galaxy 复杂 `&&`/`||` 嵌套条件会触发语法错误

### 现象

`ScriptError.txt` 报 `语法错误`，定位到含 `&&` 的 if 语句：

```c
if (((lv_isUltimate == true) && (lib67C0F0E7_gf_BitMaskTrueIndexIs(libE0EAE146_gv_abathurStartTalentMask, 1) == true))) {
```

### 根因

Galaxy 语法对某些 `&&` 复合表达式解析不稳定。注意：项目中 `||` 的简单形式（如 `if ((A == "") || (!CatalogEntryIsValid(...)))`）是可用的，问题出在"复杂表达式 + 嵌套括号 + 函数调用 + 返回语句"的组合。

### 修复

拆成嵌套 `if`，避免在 `&&` 复合条件后直接 `return`：

```c
if ((lv_isUltimate == true)) {
    if ((lib67C0F0E7_gf_BitMaskTrueIndexIs(libE0EAE146_gv_abathurStartTalentMask, 1) == true)) {
        lv_amount += 25;
    }
}
```

### 置信度

medium（基于现象归纳，未查到 Blizzard 官方语法规范说明）

### 未来护栏

建议 `validate-galaxy-scripts.py` 增加一条 lint 规则：检测 `if (.*&&.*return)` 或 `if (.*\|\|.*return)` 模式并提示拆分。

## 卡片 2：Galaxy 跨文件访问全局变量必须先在头文件声明

### 现象

`ScriptError.txt` 报 `需要布尔表达式`，定位到：

```c
libE0EAE146_gv_abathurBiomassTestPickupCreated = true;
```

### 根因

`libE0EAE146_gv_abathurBiomassTestPickupCreated` 在 `LibE0EAE146_AbathurBiomass.galaxy` 第 9 行定义为 `bool`，但未在 `LibE0EAE146_h.galaxy` 中声明。Galaxy 要求跨文件引用的符号必须有前向声明；`.galaxy` 文件内的全局变量默认不导出到其他文件。

### 修复

1. 去掉对 `gv_abathurBiomassEnabled`/`gv_abathurBiomassTestPickupCreated` 的直接访问，改调公共函数 `libE0EAE146_gf_InitializeAbathurBiomass`（其内部幂等，会自己检查 `BiomassTestPickupCreated`）
2. 在头文件补充 `libE0EAE146_gf_AbathurIsUltimateBiomassUnit` 声明

### 置信度

high

### 未来护栏

建议加一条验证器规则：扫描每个 `.galaxy` 中 `gv_*`/`gf_*` 符号的引用文件，若未在 `*_h.galaxy` 声明则告警。

### 教训

实现新功能时优先用现有公共 API，不要直接触碰其他文件的内部状态变量。

## 实现要点

### 开局天赋实现

1. 在 `AbathurRuntime.galaxy` 中添加全局变量 `gv_abathurStartTalentMask`/`gv_abathurStartTalentPlayer`/`gv_abathurStartTalentsEnabled`
2. `AbathurStartTalentsInit(player)` 从银行读取 `StartTalentMask`，若 bit 0 或 bit 1 为真则启用
3. 注册 `UnitCreated` 触发器，对新创建的战斗单位应用生物质
4. 过滤条件：`CanCollectBiomass` 通过、非 `HexTalentsIsCasterUnit`、单位属于阿巴瑟玩家
5. 初始化时也对已存在的单位应用一次（`UnitGroup` 遍历）

### 测试参数

```
-Commanders @("ZergAbathur")
-CommanderPowerOverride @("Abathur.StartTalentMask=3")
-CommanderPowerEnablePrestiges 0
-CommanderPowerEnableMasteries 0
```

`StartTalentMask=3` = bit 0 + bit 1 = 两个天赋都启用。
