## 任务备注

### 关键经验
1. **传递依赖陷阱**：`Resolve-WorkspaceModDependencyClosure` 使用 BFS 遍历 DocumentInfo 依赖闭包，即使启动脚本移除了某 mod 的直接引用，该 mod 仍可能通过其他 mod 的 DocumentInfo 传递依赖被安装。需要检查所有相关 mod 的 DocumentInfo。

2. **DocumentInfo 两种依赖格式**：
   - `<Value>file:...</Value>`（DocInfo/Dependencies/Value 格式）— `Get-DocumentInfoDependencies` 解析此格式
   - `<Dependency value="file:..."/>`（不同格式）— 当前函数不解析
   - 21 个 CommanderUnits_*.SC2Mod 使用第二种格式，但不影响本次优化（launcher 的 `$mapDependencies` 过滤逻辑已处理）

3. **PowerShell 文件编码**：`.ps1` 文件包含中文注释时必须保持 UTF-8 编码。编辑工具可能破坏编码导致所有中文变成乱码（mojibake），PowerShell 解析失败。修复方法：从 git HEAD 恢复原文件，用 Edit 工具重新应用修改。

4. **Mod 合并策略**：
   - 同名 XML 文件加后缀避免覆盖（如 `AbilData_BasePatch.xml`、`AbilData_Reborn.xml`）
   - SC2 支持多 catalog 文件覆盖同名条目
   - 不同名文件直接复制
   - `CGame` 节点的 `TriggerLibs` 声明需要合并到目标 mod 的 `GameData/GameData.xml`
   - `DataCenter.json` 的 spaces 需要追加合并
