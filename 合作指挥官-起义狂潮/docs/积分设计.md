# 积分设计

## 目标

- 0 通关时，只能开少量加成。
- 想多开加成，必须带因子。
- 随着地图逐步通关，可用加成逐步变多。
- 全图通关后，可以稳定开高配。
- 即使全图通关，想满加成也仍然要带几个因子，不能白嫖满配。

## 预算公式

`历史累计积分 + 本局因子奖励 - 本局配置消耗 >= 0`

## 积分来源

- 地图首次通关：`+10`
- 地图首次完成奖励任务：`+10`
- 指挥官首次通关：`+2`
- 普通因子：`+5`
- 中等因子：`+10`
- 高难因子：`+20`
- 随机 / 轮换随机：`+0`

## 当前可消费项

### 通用加成

- `DoubleMinerals` 矿物储量倍率
- `DoubleVespene` 瓦斯储量倍率
- `RichResources` 高产矿脉与瓦斯
- `GuardianShell` 守护者之壳
- `CreepRegeneration` 菌毯回血
- `MechanicalRepair` 机械维修
- `ChronoBoost` 时空加速
- `MaxSupply50` 人口上限 +50
- `ZeroSupply` 单位 0 人口

### 指挥官项

- 威望：每个指挥官固定 `3` 个槽位
- 额外升级：按当前数据，单指挥官约 `1` 到 `10` 个，平均 `2.83` 个

## 建议价格

### 通用加成

#### 分级项

- `DoubleMinerals`：`-2 / 级`
- `DoubleVespene`：`-2 / 级`

说明：

- 这两个收益最稳定，不能按 `-1 / 级` 算，不然新号太容易堆资源。
- 1 到 2 级还算轻量，3 级以后就已经是明显强化。

#### 固定项

- `CreepRegeneration`：`-1`
- `MechanicalRepair`：`-1`
- `MaxSupply50`：`-2`
- `GuardianShell`：`-3`
- `ChronoBoost`：`-3`
- `RichResources`：`-4`
- `ZeroSupply`：`-8`

说明：

- `菌毯回血`、`机械维修` 属于小型舒适项，给最低档。
- `人口+50` 会直接放宽运营上限，略高于舒适项。
- `守护者之壳`、`时空加速` 是明显实战强化，放中档。
- `高产资源` 是前中期滚雪球项，要比一般辅助贵。
- `0人口` 是全局级强强化，必须单独拉高。

### 威望

- 第 1 个威望：`-4`
- 第 2 个威望：`-6`
- 第 3 个威望：`-8`

说明：

- 不建议三个威望一口价。
- 叠得越多，越应该明显增压。
- 这样单开一个威望不算太贵，但三威望同开会有明显代价。

### 额外升级

- 常规额外升级：`-6 / 个`
- 强力额外升级：`-8 / 个`

建议分两档：

- `-6`：
  一般数值增强、普通解锁、局部补强
- `-8`：
  关键机制补全、核心单位质变、强经济/强人口/强技能类升级

如果暂时不想分档，也可以先统一用：

- 所有额外升级：`-7 / 个`

## 推荐实现顺序

如果想先落地简单版，建议先这样：

- `DoubleMinerals`：`-2 / 级`
- `DoubleVespene`：`-2 / 级`
- `RichResources`：`-4`
- `GuardianShell`：`-3`
- `CreepRegeneration`：`-1`
- `MechanicalRepair`：`-1`
- `ChronoBoost`：`-3`
- `MaxSupply50`：`-2`
- `ZeroSupply`：`-8`
- 威望：统一 `-5 / 个`
- 额外升级：统一 `-7 / 个`

这一版最容易直接接到当前启动器。

## 目标手感

### 0 通关

- 不带因子时，只能开 1 到 3 个小加成。
- 如果想开 `0人口`、双资源倍率、双威望这类组合，必须带因子。

### 中期

- 打过几张图后，可以稳定开常规舒适项。
- 想上高配，仍然需要 1 到 3 个中高难因子补预算。

### 全通后

- 可以稳定开大部分常用强化。
- 想满通用加成 + 多威望 + 多额外升级，仍然需要带 `2` 到 `5` 个因子。

## 参考测算

### 轻度配置

- `CreepRegeneration` `-1`

- `MaxSupply50` `-2`

### 中度配置

- `DoubleMinerals 2级` `-4`
- `DoubleVespene 2级` `-4`
- `GuardianShell` `-3`
- `1个威望` `-5`

合计：`-16`

这类配置要求已经有部分通关，或者带 1 个高难因子。

### 高配配置

- `DoubleMinerals 3级` `-6`
- `DoubleVespene 3级` `-6`
- `RichResources` `-4`
- `GuardianShell` `-3`
- `ChronoBoost` `-3`
- `ZeroSupply` `-8`
- `3个威望` `-18`
- `2个额外升级` `-14`

合计：`-62`

这类配置即使是老存档，也应该要求额外带因子，符合目标。
