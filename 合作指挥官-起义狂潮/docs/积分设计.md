# 积分设计

## 建议规则

### 加分

- 地图首次通关：`+10`
- 地图首次完成奖励任务：`+10`
- 指挥官首次通关：`+2`
- 普通因子：`+5`
- 中等因子：`+10`
- 高难因子：`+20`

### 扣分

- 通用加点：`-1 / 点`
- 威望：`-5 / 个`
- 额外升级：`-10 / 个`

## 平衡思路

- 地图首通和奖励任务是主要积分来源，鼓励扩图。
- 指挥官首通只做补充，鼓励换将，但不喧宾夺主。
- 因子给分要明显，高难因子应当能覆盖一次较重配置。
- 通用加点便宜，方便细调。
- 威望中等成本，允许组合，但不能无脑全开。
- 额外升级最贵，避免直接堆满。

## 预算公式

启动前校验：

`历史累计积分 + 本局因子奖励 - 本局配置消耗 >= 0`

## 结算记录

建议长期记录：

- 地图首通
- 地图奖励任务首通
- 指挥官首通
