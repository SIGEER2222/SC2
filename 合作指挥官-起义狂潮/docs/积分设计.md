# 积分设计

## 目标

- 0 通关时，只能开少量精通。
- 想开威望和额外加成，必须先解锁，再带因子。
- 随着地图逐步通关，军费越来越多，可开的精通和配置越来越多。
- 即使全图通关，想高配或满配，也仍然要选几个因子来补宝石。

## 双资源

- `军费`
  - 代表长期通关积累。
  - 主要用于精通。
  - 也用于支付威望和额外加成的一部分成本。
- `宝石`
  - 代表本局主动提高难度换来的资格。
  - 主要用于威望和额外加成。

## 预算公式

启动前同时校验：

- `军费收入 - 军费消耗 >= 0`
- `宝石收入 - 宝石消耗 >= 0`

任意一项小于 0，都不允许启动。

## 收入

### 军费

- 地图首次通关：`+10`
- 地图奖励任务 / 成就首次达成：`+10`
- 指挥官首次通关：`+2`
- 特殊挑战完成：`+10` 到 `+20`

### 宝石

宝石不靠通关给，主要靠因子给。

按因子难度给军费和宝石：

- 普通因子：`军费 +1`，`宝石 +1`
- 中等因子：`军费 +2`，`宝石 +2`
- 高难因子：`军费 +4`，`宝石 +4`
- 随机 / 轮换随机：`+0`

## 解锁规则

### 精通

- 默认可用。
- 只需要军费，不需要额外解锁。

### 威望

- 默认不建议全开。
- 通过特殊挑战逐步解锁威望槽位，或解锁具体威望。
- 解锁后，选择时仍然要消耗军费和宝石。

### 额外加成

- 默认只开放少量基础项，或全部锁定。
- 通过特殊挑战解锁对应额外加成。
- 解锁后，选择时仍然要消耗军费和宝石。

### 额外升级

- 默认锁定。
- 通过特殊挑战解锁对应额外升级。
- 解锁后，选择时仍然要消耗军费和宝石。

## 消耗规则

## 精通

- 精通只花费军费，不花费宝石。
- 建议：`每 1 点精通 = 军费 -1`

作用：

- 新号也能开少量基础数值。
- 通关越多，精通越能放开。
- 但精通本身不会逼玩家选因子。

## 威望

- 威望同时花费军费和宝石。

建议：

- 第 1 个威望：`军费 -2`，`宝石 -1`
- 第 2 个威望：`军费 -3`，`宝石 -2`
- 第 3 个威望：`军费 -4`，`宝石 -3`

作用：

- 单威望可以较早解锁。
- 双威望开始明显要求因子。
- 三威望必须带足够因子。
- 而且前提是对应威望已经被特殊挑战解锁。

## 额外加成

额外加成统一同时花费军费和宝石。

### 资源倍率

- `DoubleMinerals`：`每级 军费 -1，宝石 -1`
- `DoubleVespene`：`每级 军费 -1，宝石 -1`

### 一般额外加成

- `CreepRegeneration`：`军费 -1`，`宝石 -1`
- `MechanicalRepair`：`军费 -1`，`宝石 -1`
- `MaxSupply50`：`军费 -2`，`宝石 -1`
- `GuardianShell`：`军费 -2`，`宝石 -1`
- `ChronoBoost`：`军费 -2`，`宝石 -1`
- `RichResources`：`军费 -3`，`宝石 -1`

### 强力额外加成

- `ZeroSupply`：`军费 -4`，`宝石 -3`

作用：

- 额外加成不再能只靠通关点白开。
- 只要开始堆强加成，就一定会缺宝石。
- 这样就能稳定逼出因子选择。
- 同时还能用特殊挑战控制它们的开放顺序。

## 目标手感

### 0 通关

- 不带因子时，只能开很少量精通。
- 威望和额外加成基本都开不了，因为既没宝石，也没解锁。

### 前中期

- 通关后军费逐步变多，精通会先松开。
- 做完部分特殊挑战后，才开始逐步拿到威望、额外加成、额外升级的使用资格。
- 真正想用这些项目时，仍然要带因子补宝石。

### 全通后

- 军费足够支撑大量精通和大部分配置。
- 但只要想高威望、多额外加成、资源倍率、0人口一起上，还是会被宝石卡住。

## 参考测算

### 轻度配置

- 精通 6 点：`军费 -6`

合计：

- `军费 -6`
- `宝石 0`

结论：

- 新号不带因子，也能开一点基础精通。
- 但还碰不到威望、额外加成、额外升级的主体系。

### 中度配置

- 精通 12 点：`军费 -12`
- `DoubleMinerals 2级`：`军费 -2`，`宝石 -2`
- `1个威望`：`军费 -2`，`宝石 -1`

合计：

- `军费 -16`
- `宝石 -3`

结论：

- 军费主要靠通关积累。
- 宝石必须靠因子补。
- 同时默认要求这两个项目已经被特殊挑战解锁。

### 高配配置

- 精通 18 点：`军费 -18`
- `DoubleMinerals 3级`：`军费 -3`，`宝石 -3`
- `DoubleVespene 3级`：`军费 -3`，`宝石 -3`
- `RichResources`：`军费 -3`，`宝石 -1`
- `GuardianShell`：`军费 -2`，`宝石 -1`
- `ChronoBoost`：`军费 -2`，`宝石 -1`
- `ZeroSupply`：`军费 -4`，`宝石 -3`
- `3个威望`：`军费 -9`，`宝石 -6`

合计：

- `军费 -44`
- `宝石 -18`

结论：

- 全通后军费付得起。
- 但宝石仍然要求：
  - `4` 到 `5` 个高难因子，或
  - 若干中高难因子组合

这能保证全通后也必须带因子。

## 第一版建议

先按这版最容易落地：

- 精通：`军费 -1 / 点`
- 地图通关、奖励任务 / 成就、特殊挑战都给军费
- 特殊挑战额外负责解锁：
  - 威望
  - 额外加成
  - 额外升级
- 因子按难度给：
  - 军费
  - 宝石
- 威望：`军费 -2/-3/-4`，`宝石 -1/-2/-3`
- `DoubleMinerals`：`每级 军费 -1，宝石 -1`
- `DoubleVespene`：`每级 军费 -1，宝石 -1`
- `CreepRegeneration`：`军费 -1，宝石 -1`
- `MechanicalRepair`：`军费 -1，宝石 -1`
- `MaxSupply50`：`军费 -2，宝石 -1`
- `GuardianShell`：`军费 -2，宝石 -1`
- `ChronoBoost`：`军费 -2，宝石 -1`
- `RichResources`：`军费 -3，宝石 -1`
- `ZeroSupply`：`军费 -4，宝石 -3`
