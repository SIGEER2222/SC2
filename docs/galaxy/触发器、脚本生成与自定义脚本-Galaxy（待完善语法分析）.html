Delim 分隔符，空格、制表符、换行、回行
Letter 大小写单词
Digit 十进制数码

Comment 单行注释。.galaxy不支持多行注释，即使语法高亮可以正常将其识别为注释

所有的名称都可以根据UTF-8的编码规则尝试进行还原

再不济，可以参考函数声明上方的注释提示的触发器原名，非ASCII码范围内的字符都替换为了问号。脚本混淆的情况除外。

Identifier 标识符，变量名、函数名、结构体名、结构体类型
变量定义格式为(const)? {类型名} {变量名}(= {表达式})?;，其中表达式优先级高于赋值表达式。一条语句中只能声明一个变量。
全局变量名格式：(lib{库ID}_)?gv_{变量名}
局部变量名格式：lv_{变量名}
数组的声明格式：{类型名}([{Integer}]){1,n} {变量名};，维度可以不止GUI的四维
结构体类型命名格式：(lib{库ID}_)?gs_{结构体名}{{变量声明列表与默认值设置}};
定义结构体类型的对象无需添加struct为前缀。
结构体修改默认值会在触发器功能函数进行中。
毕竟有自定义脚本，怎样都有可能，主要还是得以层级结构来分作用域。

触发器

脚本生成组成：
触发器本体变量：trigger (lib{库ID}_)?gt_{标识符};
触发器运行函数：bool (lib{库ID}_)?gt_{标识符}_Func\(bool testConds, bool runActions\)。testConds代表是否核对条件，这是明确的，runActions是何时、如何传入的就不知道了，毕竟按照一般的逻辑，runActions == false，那么会直接跳出函数的执行，也不符合触发器执行动作不要等待可能会暂停并阻塞该动作函数的猜想。
函数体首先是变量声明，接着是自定义脚本自动生成的自动变量声明#AUTOVAR，然后是结构体默认值修改，使结构体成员的默认值变为结构体声明中被修改的默认值，而非数据类型本身的默认值，若一致则跳过。
当有条件时，添上反向的返回条件，一条条罗列，或使用非、与或或进行包装（括号地狱）

if (testConds) {
    // 比较
    if (!((UnitGetOwner(EventUnit()) == 1))) {
        return false;
    }

    // 非
    if (!((!((UnitGetOwner(EventUnit()) == 1))))) {
        return false;
    }

    // 与，或不再列出
    if (!((((UnitGetOwner(EventUnit()) == 1) && (UnitGetOwner(EventUnit()) == 1))))) {
        return false;
    }

    // 在界限内
    if (!(((lib1_gv_test >= 1) && (lib1_gv_test <= 100)))) {
        return false;
    }

    // 条件函数
    if (!(lib1_gf_condition({实参列表}))) {
        return false;
    }
}

当无动作时，直接return true;，否则在返回前加上

if (!runActions) {
    return true;
}

触发器注册函数，在地图初始化创建触发器实例时调用，根据预设的触发器响应事件生成相应的事件添加函数：

void (lib{库ID}_)?gt_{标识符}_Init() {
    {触发器本体变量} = TriggerCreate("{触发器运行函数}");
    // 添加触发器事件…例如：
    TriggerAddEventUnitDied(gt_MyTrigger, null);
    TriggerAddEventMapInit(gt_MyTrigger);
}

函数

若函数定义为事件类型，那么从函数声明中和使用该事件的触发器初始化函数中就可以看到，使用该事件的触发器会在初始化时，将其自身传入事件函数，作为第一个参数：

void lib1_gf_MyFunc3 (trigger t, int i) {
    // ……
}

void lib1_gt_MyTrigger_Init () {
    lib1_gt_MyTrigger = TriggerCreate("lib1_gt_MyTrigger_Func");
    // 为触发器注册事件，将触发器作为第一个参数传入事件函数
    lib1_gf_MyFunc3(lib1_gt_MyTrigger, lib1_ge_Preset_Custom_Value1);
}

选项

被限制 仅标识函数属性，是否能够运行由函数本身的性质决定，一般是固有函数
创建线程 创建一个额外的触发器对象，运用触发器线程的自动创建和不等待参数来实现另开线程，需要用到一个额外触发器auto_(lib{库ID}_)?gf_{标识符}_Trigger和触发器的内容函数定义auto_(lib{库ID}_)?gf_{标识符}_TriggerFunc，正如一般的触发器：

// 创建线程用到的触发器
trigger auto_lib1_gf_function_Trigger = null;

// 拥有创建线程选项的动作的实际函数定义
bool lib1_gf_function () {
    // 第一次运行时创建触发器对象，因为本身不会像GUI的触发器
    // 那样有一个固定的初始化函数在全局初始化时运行
    if (auto_lib1_gf_function_Trigger == null) {
        auto_lib1_gf_function_Trigger = TriggerCreate("auto_lib1_gf_function_TriggerFunc");
    }

    //不核对条件，不等待地运行函数的功能触发器，实际上实现创建线程的方法
    TriggerExecute(auto_lib1_gf_function_Trigger, false, false);
}

// 触发器运行的函数，即动作中所写的函数定义
bool auto_lib1_gf_function_TriggerFunc (bool testConds, bool runActions) {
    // Automatic Variable Declarations
    // Implementation
    return true;
    return true;
}

固有函数 绑定为固有函数之后，就单纯变为了一个函数标识符生成指示器了，就像自定义脚本的预设。可能参数的脚本标识符也不需要一致，只要数量、类型和顺序对了就成，反正生成的脚本里也用不到形参的这一信息
无脚本前缀 脚本识别符是什么，生成的脚本标识符就是什么，即不包括所属库、作用域（g-global全局、l-local局部）、元素类型（v变量、f函数、e预设什么的）这些前缀
行中 即inline内联，直接在调用位置填函数体并替换掉参数，而非调用函数。会自动对返回语句进行修改适配
循环 使得break可以break，continue可以continue
隐藏的 内部的内部，用来隐藏一些子函数类型的实现，其余作用目前只想到用来隐藏废弃函数
运算符 开启自定义脚本的功能，本质上是通过组合参数的标识符，生成运算对应的脚本语句填入调用处，例如修改变量'a':'+' '1'，会根据自定义脚本的参数引用与组合，被翻译为'a' '+'= '1'，或在无自定义脚本的情况下，按序生成参数的脚本识别符，以空格分开。
自定义脚本 纯纯的自定义脚本。若函数定义的自定义脚本非空，会导致创建动作后的文本框内容无效
自定义AI 不知道有什么具体用处
子函数 又是自定义脚本，允许动作嵌套在其下，由子函数本身提供环境，一般是循环遍历某样容器，然后对当前指向的容器内部对象进行些操作。一般用以实现控制流语句

语句（不止）

以语句结束符分号;为界。
语句可加static限定，但无法在GUI中实现。
目前确定的可用语句类型：
空语句 唯有;
变量声明+定义语句 只允许声明与定义一个变量。函数的局部变量声明必须放在函数头部。
赋值语句 右值无法为赋值表达式。优先级高于赋值表达式的表达式可用。支持组合赋值运算符，如a += b。支持的运算除了基本的加减乘除外也包括取模
函数调用 纯函数调用。不接收返回值可能，只是可能会出现错误
语句块 由{}包括在内的语句块。注意控制流语句必须使用语句块跟在后，而不能使用单条语句。
typedef语句
const整数变量数组大小

不可用语句类型：
表达式语句 优先级高于赋值表达式的所有纯表达式语句
逗号分割的表达式语句
参数 参数只能为优先级高于赋值表达式的表达式
自增自减 完全不支持自增自减
